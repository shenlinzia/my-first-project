# 菲纸打印程序旧系统试打版 v0.1

下载本目录中的 `FEIPRINT-test-v0.1.zip`：打开ZIP文件页面后点击 **Download raw file**（下载原始文件）。

在原来能运行旧打印软件的电脑上解压到新文件夹，先运行 `SAMPLE.BAT` 打印一张样纸；再运行 `START.BAT` 录入实际数据。

这是16位DOS程序，默认使用原有LPT1打印连接；支持每整张左右相同、每扎1到3份。已完成DOS模拟运行和打印数据校验，实体LQ-310的字迹、位置和速度需试打。
